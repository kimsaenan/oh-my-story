# Oh! My Story 품질 지표 (rule)

- 이야기 3편 × 최대 8페이지 · 아이 입력 27회 (한 단어·완전한 문장·상상·한국어·위험한 말)
- 엔진: 편집자 문장 (규칙 기반)

| 지표 | 결과 | 목표 | 판정 |
|---|---|---|---|
| 지침 통과율 (대사 길이·지적 금지·한국어 섞임) | 100.0% | 100% | 통과 |
| 다음 질문 + 고를 거리 제공 (T4) | 100.0% | 100% | 통과 |
| 한국어 → 영어 전환 | 100.0% | 100% | 통과 |
| 위험한 말 → 다정한 이야기 | 100.0% | 100% | 통과 |
| 페이지 생성 시간 (중앙값 / 95%) | 0.00초 / 0.00초 | 5초 이내 | 통과 |
| 주요 표현 노출률 (참고, T3) | 47.6% | (참고) | - |
| 이야기 1편당 아이가 영어로 말한 문장 | 6.0문장 | 목표 5문장 | - |
| 지침 검사 후 재생성 비율 | - | (참고) | - |

참고
- 편집자 문장(규칙 기반)은 사람이 쓴 문장이라 지침 통과율이 높은 게 당연해요. 판단은 LLM 결과와 실제 아이 녹음으로 해야 해요.
- 교재 표현은 채점하지 않아요. 노출률은 'Wacky가 표현을 자연스럽게 들려주는가'를 보는 참고 지표예요.
